# FinanceManager

A mobile application built with **React Native** (React 19.2.3, React Native 0.87.1, TypeScript) for **expense management** and **shared shopping lists**.

## Getting Started

### Prerequisites

Ensure you have your environment set up for React Native development (Node >= 22.11.0, JDK 17+, Android Studio and/or Xcode for macOS).

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Metro Bundler

```bash
npm start
```

### 3. Run on Android or iOS

```bash
# Android
npm run android

# iOS (macOS only)
npm run ios
```
